# Run the project from Chat

Use these prompts in ordinary ChatGPT Chat after connecting Remote Desktop Commander. Replace the project, language, and preferred executor as needed. Keep feedback in the same conversation.

## Connection check

```text
Use Remote Desktop Commander to identify my online paired computer. Check the operating system and relevant installed tools, including Python and any local coding agents available for this task. Report only versions and readiness information. Do not inspect or print credentials, environment variables, or unrelated personal files. Reply in English.
```

## One conversation for the whole workflow

```text
Run this project on my connected computer through Remote Desktop Commander. Start by discussing the goal, constraints, and success criteria with me. Turn our discussion into stages and a project structure. Create the folders, brief, and task files directly. Keep discussion, setup, launch control, and review here in Chat. Use Python, shell commands, or file operations for suitable work. Launch my available local coding agent only for implementation stages that need it. Track the actual process, inspect its outputs, handle focused refinements, and return a verified artifact or localhost preview. Keep changes inside the agreed project folder.
```

## Focus Kit: discuss, prepare, launch, review

Start with the idea:

```text
I want a launch page for Focus Kit, a fictional productivity tool for indie developers and designers. Let's discuss the audience, visual direction, main promise, and useful interactions first. I want a clear editorial style and a page that actually does something. Use English. Do not launch a coding agent during this discussion.
```

Prepare the project directly:

```text
Turn our agreed direction into a concise brief and stages. Through Remote Desktop Commander, create a fresh project folder with brief.md, tasks.md, v1/, and final/. Write the agreed requirements and acceptance criteria into the brief. Check the relevant installed tools without printing secrets. Do this preparation directly through file or terminal tools; keep coordination here in Chat.
```

Start the implementation:

```text
Use my available Claude Code installation to implement the agreed brief in v1/ using plain HTML, CSS, and JavaScript. Include an Editorial/Calm theme switch and a focus-session panel opened by the main CTA. Supply the agent with the brief and acceptance criteria. Track the actual run, inspect the resulting files, and run appropriate checks. Keep coordination and decisions here in Chat.
```

Review and refine:

```text
Review v1 against our brief. Send Claude a focused refinement task for the changes that matter. Preserve v1 and save the refined version in final/. Avoid invented customer claims or quote attributions. Verify the theme switch, session panel, duration selection, start, pause, and keyboard interaction. Start a localhost preview and return its URL with a concise before/after summary grounded in the actual files. If browser checks are unavailable, say exactly what you could inspect.
```

## A result through Python without a coding agent

```text
Use Remote Desktop Commander and Python directly for this task. Create a fresh demo folder and a small sample CSV with fictional project stages, owners, and completion states. Read it with Python and generate a self-contained HTML progress report showing totals and completed versus remaining stages. Keep discussion, preparation, execution, and review here in Chat. Do not launch Claude Code, Codex, or another coding agent. Check the computed totals against the CSV and return the finished report path. Use English.
```

## Another local executor

```text
Use the same project workflow with the local tool or coding agent I name. First check the relevant installed help and supported invocation. Prepare the project directly, hand over only the stages that need this executor, and track the actual run. Review its output and return the verified result. Keep coordination here in Chat.
```

The recorded Focus Kit example used Claude for both implementation passes and Chat for coordination and review. Multiple models are optional.
